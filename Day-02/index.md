# Types of Software Applications

## 1. Desktop Applications
- Run on personal computers or workstations
- Installed directly on the user's machine
- Examples: Microsoft Office, Adobe Photoshop, VLC Media Player

## 2. Web Applications (Internet) - Focus
- Accessed through web browsers
- No installation required (client-side)
- Platform-independent
- Examples: Gmail, Google Docs, Facebook

## 3. Distributed Applications - Focus
- Run on multiple computers across a network
- Components communicate over a network
- Examples: Blockchain applications, cloud storage services, multiplayer online games

## 4. AI Applications
- Utilize artificial intelligence and machine learning
- Can be desktop, web, or mobile-based
- Examples: Chatbots, recommendation systems, image recognition software

## 5. IoT Applications
- Control and manage Internet of Things devices
- Process data from sensors and connected devices
- Examples: Smart home systems, industrial automation, wearable tech

## 6. Mobile Applications
- Designed for smartphones and tablets
- Available through app stores
- Examples: Instagram, Uber, WhatsApp

## 7. 2D and 3D Gaming Applications
- Range from simple 2D games to complex 3D environments
- Can be single-player or multiplayer
- Examples: Minecraft, PUBG Mobile, Candy Crush Saga

# Web Applications - In Depth

## 1. What is the Web?
The World Wide Web (WWW) is a collection of interlinked documents and resources accessed through the internet using web browsers.

## 2. Understanding Networks

### What is a Network?
A network is a group of interconnected devices that can communicate and share resources with each other.

### Historical Context
- **1960s**: ARPANET was developed by the US Department of Defense's Advanced Research Projects Agency (ARPA)
- **1980s-1990s**: Evolution of the modern internet

### Network Types
- **LAN (Local Area Network)**: Small geographical area (e.g., home, office)
- **MAN (Metropolitan Area Network)**: City-wide network
- **WAN (Wide Area Network)**: Spans large geographical areas (e.g., the internet)
- **PAN (Personal Area Network)**: Personal devices in close proximity (e.g., Bluetooth devices)

## 3. The World Wide Web

### History
- **Early 1990s**: Invented by Sir Tim Berners-Lee at CERN
- Web is a subset of the internet with controlled access
- Inspired by the concept of a spider's web, where connections require permission

### Web Access Models
1. **Anonymous/Guest Users**
   - Limited access to public resources
   - No personalization

2. **Authorized Users**
   - Authenticated access
   - Personalized experience
   - Access to protected resources

## 4. Web Technologies

### HTML (HyperText Markup Language)
- Invented by Tim Berners-Lee
- **HyperText**: Text containing links to other documents
- **Markup Language**: Defines structure and presentation of content

### Evolution of Markup Languages
1. **GML** (Generic Markup Language)
2. **SGML** (Standard Generalized Markup Language)
3. **HTML** (HyperText Markup Language)

### Standardization
- **IETF** (Internet Engineering Task Force)
  - Managed HTML up to version 3.2
  - Initially, web was text-based with limited multimedia support

### Modern Web Standards
- **W3C** (World Wide Web Consortium)
- **WHATWG** (Web Hypertext Application Technology Working Group)
  - Formed in 2004
  - Responsible for HTML5 and modern web standards

## 5. Current Web Standards
- **HTML5**: Latest major version of HTML
- **CSS3**: For styling and layout
- **JavaScript**: For client-side interactivity
- **Web APIs**: For advanced functionality
